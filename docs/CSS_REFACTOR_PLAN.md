# Custom.css 重构计划

## 目标

1. **拆分文件** - 将 1669 行单文件拆分为模块化结构
2. **合并同类项** - 统一分散的样式（卡片、暗色模式、响应式）
3. **统一命名** - 采用 BEM 命名规范

1. **卡片样式分散** - 基础卡片(109-145)、Hero卡(859-876)、摘要截断(927-943)

4. **命名不统一** - 混用 `entrance-hero__` 和 `article-link--`

## 重构方案

### 目录结构

```
assets/css/
├── custom.css (主入口，仅导入)
├── tokens.css (设计令牌)
├── base.css (基础样式)
├── components/
│   ├── card.css (卡片组件)
│   ├── hero.css (Hero区域)
│   ├── timeline.css (时间轴)
│   ├── podcast.css (播客播放器)
│   └── navigation.css (导航、页脚)
├── effects/
│   ├── steamwave.css (蒸汽波网格)
│   └── dotfield.css (DotField效果)
├── pages/
│   ├── home.css (首页特定)
│   ├── article.css (文章页)
│   └── list.css (列表页)
└── dark-mode.css (暗色模式统一)
```

### 命名规范

```css
/* BEM 命名：[block]__[element]--[modifier] */
.card { }
.card__title { }
.card__meta { }
.card--featured { }

/* 页面命名：page-[name] */
.page-home { }
.page-article { }

/* 状态命名：is-[state] / has-[state] */
.is-active { }
.has-shadow { }

/* 暗色模式：统一使用 [data-theme="dark"] */
[data-theme="dark"] .card { }
```

### 合并策略

#### 1. 卡片组件合并

**当前分散位置**：
- 第109-145行：基础卡片样式
- 第146-159行：卡片标题
- 第160-172行：卡片 meta
- 第859-876行：Hero卡特殊样式
- 第927-943行：摘要截断

**合并后结构**：
```css
/* components/card.css */
.card { }
.card__title { }
.card__meta { }
.card__summary { }
.card--featured { }
.card--hero { }
```

#### 2. 暗色模式统一

**当前问题**：`.dark` 选择器分散在 20+ 处

**解决方案**：
```css
/* dark-mode.css */
[data-theme="dark"] {
  /* 所有暗色模式变量 */
}

[data-theme="dark"] .card { }
[data-theme="dark"] .hero { }
/* ... */
```

#### 3. 响应式统一

**当前问题**：`@media` 查询散布在各处

**解决方案**：
```css
/* base.css 末尾 */
@media (max-width: 768px) {
  /* 所有移动端样式 */
}
```

## 风险控制

### 风险点

1. **样式丢失** - 拆分过程中可能遗漏
2. **优先级冲突** - 文件顺序影响 CSS 优先级
3. **暗色模式破坏** - 暗色模式样式不完整
4. **响应式问题** - 媒体查询丢失

### 缓解措施

1. 每次拆分后完整测试所有页面
2. 保持 `custom.css` 作为主入口，控制导入顺序
3. 使用 Git 分支进行重构，便于回滚
4. 建立视觉回归测试
